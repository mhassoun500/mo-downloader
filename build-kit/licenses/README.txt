MO Downloader bundles these open-source tools, each under its own license:

- yt-dlp (Unlicense)            https://github.com/yt-dlp/yt-dlp
- FFmpeg (LGPL/GPL)             https://ffmpeg.org  (via imageio-ffmpeg)
- Deno (MIT)                    https://deno.com
- aria2 (GPL-2.0-or-later)      https://github.com/aria2/aria2  — source: https://github.com/aria2/aria2/releases/tag/release-1.37.0
